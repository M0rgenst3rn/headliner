# MS Render

**Retro 3D effects for live text and shapes in Photoshop** – chrome, gold and silver extrusions with
bevels, outlines and hard retro shadows, rendered from your live text so it stays editable.
Part of the MS family with [MS Distress](https://github.com/M0rgenst3rn/ms-distress) and
[MS Printer](https://github.com/M0rgenst3rn/ms-printer).

> **Status: Phase 2.** 24 effects you can stack, 15 combo looks, export for print, a clickable thumbnail gallery, neutral studio preview and colour wheel.

![First render in Photoshop](docs/images/first-render-photoshop.jpg)

## Effects
| Replaces the look | Behind the layer | On top of the layer |
|---|---|---|
| Chrome Extrude, Inflate, Bevel, Glass, Halftone, Brushed Metal, Diamond Plate, Rust, Wood, Marble, Stone | Shadow (long / drop / perspective), Glow, Corona, Backlight, Fire, Smoke, Motion Trail, Retro Stack, Sticker | Lightning, Electrify, Star, Snow, Water Drops |

**Chrome Extrude** comes in 10 materials – chrome, gold, silver, rose gold, copper, black chrome, ice, synthwave,
holographic and your own colours (sky and ground of the reflection) – with a movable horizon, shine, colour-gradient
side walls (the classic 80s look), outline and second outline in any colour and a coloured hard shadow.

**Materials** fill the letters with a procedural texture (no image files): brushed metal in any colour, diamond
plate, rust with adjustable corrosion, wood (oak, walnut, pine, ebony), marble (Carrara, black & gold, verde, rose)
and stone (granite, sandstone, slate, lava rock) – with relief, bevel and light angle.

Every effect has its own looks (presets). Sizes are in % of the text height, so a look scales with your text.

## What works today
- **Effect stacks**: combine effects like layers – e.g. Chrome Extrude + Glow + Lightning. One effect can
  replace the look (the base); the others sit on top or behind it and follow its shape (a glow wraps the
  extruded 3D letters, not just the flat text). **+ Add effect**, click to swap, ▲▼ to order, ● to hide,
  ✕ to remove. Each effect becomes its own layer in the group
- **Combos**: ready-made stacks such as Thunder Chrome, Flame Biker, Neon Sign, Toxic Slime, Frozen, Hot Rod,
  Gold Sparkle, Eclipse, Solar Gold, Rust Belt, Marble Luxe, 70s Groove, Sticker Pop, Comic Burst and Storm.
  A combo keeps your own look when it uses the same one (your silver Chrome stays silver with Flame Biker);
  ⌥-click a combo for its own look, or “+ Add effect” first to add it on top of the stack
- **Effect gallery**: thumbnails of every effect rendered with *your* selected text – click one and it is
  applied to the canvas. Below it, thumbnails of the looks for the selected effect
- **Live preview** in the panel: Chrome Extrude on the GPU (WebGL 2, 1–5 ms), the other effects on the CPU
  engine at preview size. **Drag in the preview** to move the vanishing point (Chrome Extrude) or set the
  direction (Shadow, Motion Trail), the start and end of a lightning bolt or the light behind the text (Backlight)
- **Live text stays live**: the source layer goes into a group *"MS Render · …"* together with the render.
  Change the text and the render updates automatically
- **A rendered group is final**: it holds exactly the render and its source. A new layer Photoshop drops into
  the group (e.g. new text right after rendering) is moved out automatically, so it stays a normal layer and can
  get its own effect. **Apply** adds an effect to a plain layer, **Update** changes the selected group; Live only
  ever updates existing groups
- **Settings are stored in the layer** (XMP) – select the group later and the panel restores effect and settings
- **Expands the canvas** when the effect doesn't fit
- **Export for print**: the selected group (or all visible layers) as a transparent PNG, trimmed to the design,
  at 300 dpi and a print width in cm. **Hard edges (DTF)** removes all semi-transparent pixels, which DTF printers
  would otherwise turn into halftone fringes. Works on a copy – the document stays untouched
- **Live mode** (one history step), self-test (142 checks: every effect, look and combo, building stacks, gallery, drag, live, remove, several texts in one document)

## Install (macOS)
```bash
bash install-mac.sh
```
Restart Photoshop → **Plugins › MS Render**.

## Use
1. Select a text or shape layer
2. Click an effect (or a look) in the gallery – it is applied right away
3. Fine-tune in *Settings* or drag in the preview, then **Render** again (or enable **Live**)
4. **Remove** puts the original layer back

## Project layout
```
render/          the plugin
  engine.js      core: distance fields, Chrome Extrude CPU renderer
  effects.js     effect registry: all 24 effects, controls, looks, stacks and combos
  preview/       live preview + gallery thumbnails (WebView; fx.js is generated by tools/bundle.js)
  main.js        Photoshop integration (group, XMP, live text, self-test)
tools/           bundle step, Node gallery renderer, icon generator, browser preview harness
```
